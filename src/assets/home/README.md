# Willkommensbild

Lege hier eine Datei namens `welcome.jpg` ab (möglich sind auch `.jpeg`, `.png`, `.webp`, `.avif`, `.svg` oder `.gif`).
Sie ersetzt auf der Startseite automatisch den Platzhalter – am Code musst du nichts ändern.

Das Bild wird höchstens 560 × 400 Pixel groß angezeigt. Etwa 1200 Pixel Breite genügen (für scharfe Darstellung auf Retina-Bildschirmen), möglichst unter 300 KB.
Den Alternativtext für Screenreader findest du in `src/content/de.js` und `en.js` unter `home.imageAlt`.
